🗳️ Online Polling System
 - A secure and efficient Online Polling System developed using React, Python & Django.
 - It enables authenticated users to vote digitally while ensuring one user, one vote, transparency, and fast result generation.

🎯 Objective
 - To replace traditional manual voting with a digital, secure, and scalable voting solution that minimizes errors, prevents fraud, and provides real-time results.

✨ Key Features
 - Secure user registration & login
 - Aadhaar-based OTP verification (academic simulation)
 - Admin-controlled poll creation
 - Secure vote casting
 - One Aadhaar → One Vote enforcement
 - Result display after poll completion

👥 Roles
 - Admin : Manages users, polls, candidates, and results
 - Voter : Authenticates using OTP and casts vote securely

🛠️ Technology Stack
 - Frontend : React, HTML, CSS, JavaScript
 - Backend : Python, Django Framework
 - Database: PostgreSQL
 - Security: OTP verification, encryption, role-based access control

🚀 Advantages
 - Eliminates manual voting errors
 - Faster and accurate result generation
 - Secure and transparent voting process
 - Scalable for large number of users
 - User-friendly interface

📌 Conclusion
 - The Online Polling System provides a modern and secure approach to digital voting.
 - It demonstrates real-world concepts of authentication, security, and system scalability, making it suitable for academic and learning purposes.
